# Tiny Telegram File Compressor v1.2.1

- Raised the maximum archive-part size to **2,097,152,000 bytes (2,000 MiB)**, matching the ceiling in Telegram's documented free-account configuration: 4,000 parts of 524,288 bytes.
- Telegram Desktop displays a full volume of this size as **2,000 MB**. The previous 2,000,000,000-byte setting displayed as 1,907.3 MB.
- Updated interface labels in all nine languages, command-line help and documentation to use MiB instead of decimal GB.
- Single-volume archives below the new ceiling retain the `.7z` extension. Multipart archives retain `.7z.001`, `.002`, etc.

The server supplies Telegram's actual account limits at runtime; its published configuration is the reference for this fixed ceiling. References: [client configuration](https://core.telegram.org/api/config#upload_max_fileparts_default), [file upload](https://core.telegram.org/api/files).

Download the Windows x64 ZIP, extract it and run `TinyTelegramFileCompressor.exe`. Python and image codecs are included; 7-Zip is installed separately.
