# Tiny Telegram File Compressor v1.2.0

- New **Images** tab, translated into all nine interface languages.
- Added Russian, Hindi and Simplified Chinese throughout the interface.
- Tabs are ordered **Extract**, **Images**, **Compress**, opening on Extract.
- Collect JPG, PNG, WebP, GIF, BMP, TIFF, ICO and AVIF images from all descendant folders into the selected root.
- Files already in the root are excluded from scanning.
- Existing names with the same byte size are skipped. Different sizes use `_1`, `_2`, etc.; existing files are never overwritten.
- AVIF files become JPG copies (quality 95, white background for transparency). Original AVIF files remain unchanged. Animated AVIF uses the first frame.
- Repeating collection recognizes existing copies, including numbered copies and converted JPG files, by output name and size. Equal size is not a content hash comparison.
- Progress, cancellation after the current image, logs and a final summary are included.

The Windows executable includes Pillow and AVIF support. Source users should install `requirements.txt`.
