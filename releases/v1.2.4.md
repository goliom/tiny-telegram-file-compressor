# Tiny Telegram File Compressor v1.2.4

- New unchecked option in Compress: delete the source folder and its contents after successful archiving. The published archive is tested with 7-Zip and source metadata is checked for changes before deletion. Sources are preserved if these checks fail; overlapping selected folders are rejected when deletion is enabled.
- The folder selected in Extract is now added to step 1 (Choose folders) in Compress. Its parent becomes step 2 (destination). Images still uses the selected folder.
- All nine languages updated.
