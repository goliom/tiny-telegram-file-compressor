# Privacy policy

Tiny Telegram File Compressor is a local Windows utility. It does not collect telemetry, register accounts, send analytics or upload your files. It does not access a Telegram account or send files to Telegram.

The application reads the folders and archives you select and writes results to the selected destination. Compression preserves source folders. Extraction can delete source archives only when you select deletion after successful extraction. Local progress logs and an extraction resume journal may contain file names and paths; they remain on your computer.

The application invokes your separately installed copy of 7-Zip for compression and extraction. It does not automatically download or install software, check for updates over the network, or change Windows security settings.

Visiting the GitHub repository, downloading a release, posting an issue or using a third-party signing service is separate from running the application and is subject to that service's privacy policy. Avoid including private file paths or personal files in public issue reports.

The maintainer is [goliom](https://github.com/goliom). Questions about this application can be raised through the repository's issue tracker.
