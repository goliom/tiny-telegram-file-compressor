Tiny Telegram File Compressor - application icon

Created with the built-in imagegen tool for this local application.
Prompt: transparent Windows application icon combining Telegram's white
paper airplane on a blue circle with an overlapping bold black "7z" badge
on a white tile; simple shapes readable at small sizes, no other text.

tiny-telegram-file-compressor-source.png: original generated asset.
tiny-telegram-file-compressor.png: 256x256 PNG for Tk.
tiny-telegram-file-compressor.ico: Windows icon with 16, 24, 32, 48, 64,
128 and 256 pixel sizes.

The PNG and ICO are format/size conversions of the original generated image.
The application itself needs only Tk/Python; Pillow was used at build time
to convert the image and is not required to run the tool.
