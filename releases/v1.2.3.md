# Tiny Telegram File Compressor v1.2.3

## Images
- Optional source-folder naming: `Model_1.png`, `Model_2.jpg`, etc., using the immediate parent folder and numbering from 1. Unchecked by default.
- Optional AVIF/WebP to JPG conversion, checked by default. Uncheck to copy the original formats and bytes, including when renaming by folder.
- Live naming examples, format guidance and an explicit label for the scan folder and copy destination. Original images and existing output files remain protected.

## Easier workflow
- The folder chosen in Extract supplies the Images root, compression destination and folder-dialog defaults. Each tab can still use a different location.
- A short description follows the active tab, with clearer copy-option labels and visible archive-deletion warnings.
- More visible completion summaries and an Open folder button for the results.
- The version number appears in the Windows title bar instead of beside the in-app heading.
- All new guidance is available in the nine supported languages.

## Validation
- Automated Windows tests and standalone executable checks cover compression, extraction, image conversion, original-format copies and folder-based image naming.
