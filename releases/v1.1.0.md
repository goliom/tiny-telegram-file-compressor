# Tiny Telegram File Compressor v1.1.0

- **Two new languages:** German (Deutsch) and Dutch (Nederlands), bringing the interface to six languages.
- **Single-file archives:** when compression produces only one volume smaller than 2 GB, its extension is now `.7z`. No manual renaming is needed.
- **2 GB per file:** split archives still use `.7z.001`, `.7z.002`, etc. The maximum is exactly 2,000,000,000 bytes per part (decimal GB). This is the same byte limit as the previous 2,000 MB setting.

Normal compression, source-folder preservation, progress estimates and recursive extraction remain available.

## Windows download

Download **TinyTelegramFileCompressor-v1.1.0-windows-x64.zip**, extract it and run **TinyTelegramFileCompressor.exe**. Python is included; install [7-Zip](https://www.7-zip.org/) separately.

The executable is unsigned. The ZIP contains quick-start instructions and license notices. The standalone EXE is also provided.

The source ZIP, build information and SHA-256 checksums are attached for verification.
