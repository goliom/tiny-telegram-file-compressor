# Tiny Telegram File Compressor v1.0.0

The first release of Tiny Telegram File Compressor: a Windows utility for preparing multipart archives for Telegram and extracting archive collections.

## Download

- **Recommended:** `TinyTelegramFileCompressor-v1.0.0-windows-x64.zip` — extract it and run `TinyTelegramFileCompressor.exe`. Includes quick-start instructions and runtime license notices.
- `TinyTelegramFileCompressor-v1.0.0-windows-x64.exe` — the same standalone Windows 64-bit application.
- `tiny-telegram-file-compressor-v1.0.0-source.zip` — source code, tests and build instructions.
- `SHA256SUMS.txt` — SHA-256 checksums for the release downloads.
- `BUILDINFO.json` — build-tool versions, source fingerprints and the executable smoke-test result.

**The Windows executable includes Python and Tk. Install [7-Zip](https://www.7-zip.org/) separately.** The executable is unsigned.

## Features

- Create an independent multipart 7z archive set for each selected folder.
- Maximum **2,000 MB (2,000,000,000 bytes) per part**, with Normal compression.
- Add folders from different drives and choose a shared archive destination.
- Checkbox list with folder location, size and processing status.
- Extract ZIP, RAR and 7z archives recursively, including supported multipart sets and nested archives.
- Avoid redundant same-name directory wrappers without overwriting existing files.
- Keep archives or delete them only after successful extraction.
- Resume recognition of completed extractions using a local journal.
- Current-item progress, weighted overall progress, approximate remaining time and an expandable log.
- Stop after the current item, clear completion summaries and a shortcut to open the destination.
- French, English, Spanish and Italian interfaces.

## Notes

- Windows x64 only for this executable.
- The application prepares files locally; send the generated parts through Telegram yourself.
- The first interface language is French; choose another language from the top-right menu.
- Some detailed backend errors and console messages remain French.
- Archive sets must have all volumes present. Password-protected, damaged or conflicting archives are kept and reported.
- Leave `.decompression-tout.json` in the extraction root if you want subsequent runs to recognize completed extractions.
- This project is independent of Telegram and 7-Zip. Application source code is licensed under MIT.
