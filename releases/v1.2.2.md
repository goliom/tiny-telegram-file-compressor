# Tiny Telegram File Compressor v1.2.2

- **Extract:** Delete after success is selected by default. Choose Keep archives to retain them. Failed archives are always preserved.
- **Images:** automatic WebP to JPG conversion, alongside AVIF. Original images stay in their subfolders. Transparency uses a white background; animated images use the first frame.
- Existing files are preserved; different-size name collisions receive numbered suffixes.
